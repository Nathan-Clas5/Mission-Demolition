To improve the gameplay, I had noticed that the game was very hard to do anything in, due to the way the tutorial had made it so the castles explode on impact, leaving a jumbled mess that's hard to get through.
Instead, I decided to make it so if the block is hit at a certain speed, the block is destroyed, which at the current setting, it should only do to 1 or 2 per projectile. 
This makes the game more manageable to win, since it was already hard enough to reach the center, much less actually make progress to see the screens.
